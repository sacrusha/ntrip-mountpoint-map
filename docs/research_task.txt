Research public NTRIP RTK casters for [entry]. Use WebSearch, WebFetch, curl. Unknown > guesses.

Start with national/regional mapping agencies in local administrative language; find the operator portal in the primary language. Fill gaps via RTK hobbyist and professional communities. Facts, no fluff, for ai consumption
Skip SBAS/DGNSS-only services.

For each caster found, collect:
- landing_url — operator-owned where available; most-official otherwise
- access_url — best page to allow user to find what the network is, how to sign up, and the conditions
- host:port — curl the sourcetable; note date
- tariff — all tiers, local currency, VAT stated, date observed, source URL
- num_stations — physical CORS count
- vrs — yes/no/? - includes NTRK
- hobbyist_eligibility — yes/no/?
- legal_residency_required — yes/no/?
- last_confirmed_alive — date + what was tested (sourcetable / login portal)
- datum_epoch — Datum & Epoch + URL of the official declaration. Omit if not citable. The ONLY citable source is the operator's own portal/spec sheet/decree. EPSG, Wikipedia, NGS/NOAA explainers, vendor blogs are NOT citable for this field. Semi-dynamic datums (AU GDA2020 @ 2020.0, NZ NZGD2000 @ 2000.0) ship a published velocity model — note if1f the operator does. Do NOT fetch generic primer pages (ex: epsg.io, geodesy.noaa.gov/CORS, spatial.nsw.gov.au explainer PDFs, en.wikipedia.org/wiki/ITRF)

Recent changes to spec: registration removed, landing_url&access_url added, datum_epoch added

unreachable URLs are acceptable, but require extraordinary evidence that they are reachable for a target user, and evidence-backed explanation why you cannot reach them.

If no active caster: most recent project/announcement (date + URL). Note nearest viable cross-border alternative if within ~50 km.

Don't access centipede/rtk2go/nota online, unless that is the entry you are researching.
