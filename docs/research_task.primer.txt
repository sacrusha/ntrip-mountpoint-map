NTRIP RTK research primer. Audience: agents running docs/research_task.txt. Self-contained operational knowledge. Deeper material: docs/gnss-ai-guide.md (load section only if primer insufficient). AI-only file; compression per /caveman skill at level full (see CLAUDE.md).

abbrev: MP=mountpoint, ST=sourcetable, NRTK=Network RTK, VRS=Virtual Ref Station, MAC=Master-Aux Concept, FKP=Flachen-Korrektur-Parameter, SSR=State-Space Repr, OSR=Observation-Space Repr, CORS=Continuously Operating Ref Station, IAR=Integer Ambiguity Resolution, ITRF=Internat Terr Ref Frame, IGS=Internat GNSS Service.

[scope]
in: RTK + NRTK over NTRIP. Free, public, hobbyist-eligible.
out: PPP, PPP-RTK, SSR/SPARTN (Galileo HAS, QZSS CLAS, BeiDou PPP-B2b, Trimble RTX, NovAtel TerraStar, u-blox PointPerfect, Swift Skylark). SBAS (WAAS/EGNOS/MSAS/GAGAN/SDCM). DGNSS-only (pseudorange).
quick test: carrier-phase + RTCM 3.x + NTRIP -> in. otherwise -> out.
mixed networks (RTK + SBAS + PPP): in iff >=1 RTK MP exists. document only RTK side.

[ntrip]
3 roles: NtripSource (base pushes RTCM) -> NtripCaster (HTTP server, holds ST) -> NtripClient (rover GETs MP).
port 2101 = convention only. real-world: 80, 443, 2101-2104, 5005, 9879, 10011. some casters expose 443 TLS for firewall traversal.
auth: B=basic, D=digest, N=none. ST field 15.
v1 vs v2: v1=HTTP/1.0, GET /MP, GGA out-of-band. v2=HTTP/1.1 chunked, GGA in-band. most casters dual-mode. older Trimble = v1 only.

[sourcetable]
HTTP GET / on caster (no MP). probe: `curl -A 'NTRIP/1.0' --max-time 8 http://host:port/`. some casters close on default curl UA -- retry with NTRIP-style UA before declaring dead.
3 record types: STR (stream), NET (network), CAS (caster).
STR field index, 0-based:
  0:"STR" 1:MP 3:format(RTCM ver+msgs) 5:carrier 9:lat 10:lon 11:nmea 14:fee
field 5 carrier: 0=DGNSS, 1=L1, 2=L1+L2, 3=tri-band. carrier=0 -> OUT.
field 11 nmea: 1 -> caster needs rover GGA -> any NRTK (VRS/MAC/FKP/i-MAX) OR routing alias. 0 + valid lat/lon -> single-base physical station.
field 14 fee: "N"=free at protocol. does not imply unrestricted; may need registration (see [licensing]).
routing aliases, NOT physical stations, do NOT count in num_stations:
  NEAR (rtk2go, Centipede): routes to closest base by rover GGA. nmea=1.
  AUTO/VRS-named MP: single entry-point -> per-rover synthetic stream. nmea=1.
use scripts/stations_by_country.py + stations_by_radius.py for our local sources; they apply nmea_filter/solution_filter correctly (see scripts/fetch_stations.proc.md).

[nrtk-detection]
nmea=1 in ST -> NRTK or routing alias. distinguishing the 4 modes from ST alone usually impossible; operator docs or stream inspection needed.
research field vrs: yes (any NRTK confirmed - VRS/MAC/FKP/i-MAX), no (single-base only), ? (unknown).
4-mode summary (full: gnss-ai-guide.md §6):
  VRS   server interpolates per rover. Trimble origin. most commercial NRTK.
  MAC   rover interpolates from master+aux deltas. RTCM 1014-1017. Geo++/Leica; some SAPOS, swiss swipos, EUREF.
  FKP   rover evaluates polynomial atm coeffs per sat. RTCM 1034. SAPOS legacy, some AT.
  i-MAX MAC-format frames but server-interpolated (degenerate). Trimble.
all 4 carry nmea=1; same scope decision (all in).

[stations-vs-mps]
not all MPs = physical stations:
  multi-format streams from one station (RTCM3 + CMR + legacy + MSM-only) -> count station once.
  routing aliases (NEAR/AUTO/VRS) -> 0 stations.
  test/dev MPs -> not user-facing; exclude unless operator presents them.
not all stations appear in ST:
  NRTK casters may publish only the network MP, hide individual stations -> num_stations from operator portal, not ST line count.
  per-station ST records on networks like AUSCORS = individual streams visible to rovers.
num_stations = physical CORS count; treat as the count an operator publishes; cite source.

[base-roles]
CORS = continuously operating reference station. real physical RTK base, real-time RTCM via NTRIP.
IGS station != CORS in this project's sense. network.igs.org publishes ~500 stations; many post-process only (RINEX archive, no real-time RTCM). check "real_time_systems" / "Streams" field on the IGS station page or operator caster ST. station on a public NTRIP caster ST -> real-time CORS = in scope. station only on IGS archive -> out.
single-base RTK MP = 1 CORS, 1 stream. effective up to ~10-30 km. degrades via ppm.
NRTK MP = multi-station synthesis, effective baseline ~0 km inside network hull (<=70 km spacing); degrades fast outside hull (silent extrapolation, dm-m errors, no RTCM warning).

[datum-epoch]
datum = geodetic frame coords expressed in. examples: ETRS89, NAD83(CSRS), GDA2020, CGCS2000, ITRF2014, IGS20, WGS84(Gxxxx).
epoch = date station coords anchored. examples: 2010.0, 2020.0.
why: rover position output adopts base frame. wrong frame -> cm-dm shift; grows ~2-7 cm/yr via tectonic drift. same-frame hobbyist use unaffected; cross-frame work is not.
plate-fixed national frames (ETRS89, NAD83(CSRS), CGCS2000, SIRGAS2000): tied to continental plate; drift only across plate boundaries.
global realizations (ITRFyyyy, IGSyy, WGS84(Gxxxx)): used by international casters (EarthScope NOTA, IGS, BKG).
semi-dynamic (AU GDA2020 @ 2020.0, NZ NZGD2000 @ 2000.0): publish velocity model; cm-accurate transform needs coord + per-station velocity.
operational citation rule (also in research_task.txt): only operator portal/spec/decree citable. EPSG, Wikipedia, NGS/NOAA explainers, vendor blogs NOT citable. no operator declaration -> `omitted -- no citable declaration`. do NOT infer from continental plate, neighbour country, or EPSG-suggested CRS.

[licensing]
3 families -> hobbyist_eligibility:
  CC BY / national-survey-free  AU, NZ, most EU national CORS, BR, CO     yes; citation on publications
  NULA-style non-commercial     EarthScope NOTA                            yes for personal; no for paid work (real -- landscaper-for-pay -> not free)
  volunteer-pool implicit       rtk2go, community Centipede                yes; "use freely don't abuse"
  restricted / paid             Gulf-state networks, some DE Lander tiers  no (free hobbyist tier absent)
rebroadcast: re-serving any of the above via your own caster -- forbidden by nearly all terms. str2str ease != legal permission.

[accuracy]
RTK acc = fixed_mm + (ppm * baseline_km). typical hobbyist hardware (Emlid RS2+, ZED-F9P + survey antenna): 7mm + 1ppm.
@10km ~17mm. @30km ~37mm. >30km single-base = marginal.
VRS inside hull (<=70km station spacing) ~0km effective baseline -> ~7-8mm regardless of nearest physical station. outside hull = silent extrapolation, dm-m errors, no warning.
relevance to research: single-base CORS 30+km from user = marginal. NRTK with <=70km spacing = good throughout hull. note when operator publishes baseline guidance.
